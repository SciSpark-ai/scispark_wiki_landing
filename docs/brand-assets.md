# Selected SciSpark artwork

These files are selected production assets copied from the user-supplied
`SciSpark_paper_manager/assets/brand/` kit. Keep the originals unchanged.

- `public/brand/wordmark.png`: transparent wordmark, an existing raster extraction.
- `public/brand/sparky-idle-light.svg` and `sparky-idle-dark.svg`: supplied companion exports.
- `public/brand/spark.svg`: supplied orange vector symbol.
- `public/favicon.svg`, `public/apple-touch-icon.png`, and the app's `favicon.ico`: supplied
  favicon exports.

The CSS frames the wordmark's original clear-space bounds and reverses its ink
for dark mode. No substitute font, generated logo, or blend-mode background is used.
